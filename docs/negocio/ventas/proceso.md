# Proceso de venta

## Calificar antes de demostrar

1. Confirmar números y WABA del negocio.
2. Estimar chats cerrados y burbujas salientes por número; no mezclar unidades.
3. Medir cuántos chats terminan hoy en pedido, reserva o pago confirmado.
4. Identificar tareas repetidas, comprobantes, audio, imágenes y derivación.
5. Acordar qué evento exacto será una venta cerrada.

## Demostración del happy path

Mostrar con datos del prospecto: consulta → recomendación → datos del pedido → instrucción de pago → comprobante → confirmación humana → cierre. Mostrar también un chat cerrado sin venta y una derivación; vender realidad operativa, no una demo perfecta.

## Cierre

- Elegir plan por número y cotizar instalación.
- Presentar una mensualidad final con IGV que incluye Meta, IA, hosting, soporte y herramientas.
- Explicar chats aproximados, techo de respuestas y avisos al 80%/100%; nunca ofrecer ilimitado.
- Aclarar capacidad aproximada, guarda interna de mensajes y regla de exceso.
- Diferenciar demo gratuita en número AIbot del piloto vivo con S/250 + IGV de activación más el plan.
- Ofrecer 3/6/12 meses según la política; no descontar números adicionales.

Una venta válida requiere pago de AIbot, número activado y primer chat real atendido. El precio se valida tras cinco números pagados, no con interesados.

Ante una objeción de capacidad, reducir burbujas redundantes y medir P50/P90. Marketing y un BSP puente se cotizan aparte.
